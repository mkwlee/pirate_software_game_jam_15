# Alchemy In the Darklands

*A top-down action-shooter developed for Pirate Software – Game Jam 15*

This is a **rough prototype** created during the game jam. The concept came to life under tight time constraints—only half of the allotted development window was available—but the core idea resonated strongly and propelled the project forward!

🔗 [Play it on itch.io](https://matthewtofu.itch.io/alchemy-in-the-darklands)

---

## 🎮 Features

- **Movement & Combat**
  - `W/A/S/D` to move
  - `SPACE` to dash
  - `Left Click` and `Right Click` to cast spells or shoot

- **Spell Customization**
  - Drag and drop spells onto others to apply modifiers
  - Reapplying to an already-modified spell replaces its base
  - Hover over spells to see tooltips for more info

---

## 🚧 Game Status

- ⚠️ **Prototype** – actively WIP and not a polished release
- Built with **Godot Engine**
- Web export (HTML5) playable in-browser
- Genre: **Action**, **Top-Down Shooter**, **Magic**

---

## 🕹️ How to Play

1. **Play it online**:  
   [👉 Play on itch.io](https://matthewtofu.itch.io/alchemy-in-the-darklands)

2. **Controls:**
   - `W/A/S/D` — Move
   - `SPACE` — Dash
   - `Mouse Buttons 1 & 2` — Cast spells / Shoot
   - Drag and drop spells in the UI to customize your loadout
